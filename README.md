# Student Management System in x86 Assembly (MASM)

A menu-driven CRUD application written entirely in x86 assembly using MASM and the Irvine32 library.

## Features
- Add a student (ID, name, grade, GPA)
- View all students in a table
- Search by ID
- Delete by ID
- Stores up to 20 records in a `STRUCT` array

## Concepts demonstrated
`STRUCT` definitions, arrays and pointer arithmetic, procedures (`PROC`), loops, conditional jumps, stack operations, string and console I/O.

## Build & run
Needs Visual Studio with MASM and the Irvine32 library configured. Add `student_management.asm` to an assembly project and build as 32-bit.
